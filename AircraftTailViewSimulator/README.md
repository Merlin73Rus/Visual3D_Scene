# Aircraft Tail View Simulator

Программа для формирования навыков пространственной ориентации на основе визуализации воздушного судна с видом от хвостового оперения.

## Описание

Программа предназначена для формирования у студентов гражданской авиации базовых навыков пространственной ориентации посредством визуального анализа динамики полета. Реализована трехмерная модель воздушного судна, отображаемая с фиксированной внешней точки - с видом от хвостового оперения на неподвижный фон земли. Такая визуализация обеспечивает устойчивое восприятие пространственного положения и угловых перемещений воздушного судна в горизонтальной и вертикальной плоскостях. Программа служит основой для последующего перехода к интерпретации приборной информации и используется на начальном этапе обучения на процедурных тренажерах. Управление самолетом осуществляется с джостика Logitech Extreme 3D Pro.

## Архитектура

Программа состоит из следующих основных компонентов:

1. **3D Визуализация** - отображение модели воздушного судна с фиксированной точки обзора от хвостового оперения
2. **Система управления** - интеграция с джойстиком Logitech Extreme 3D Pro
3. **Физическая модель полета** - реализация базовой аэродинамики для обучения
4. **Интерфейс пользователя** - элементы управления и отображения параметров полета

## Зависимости

Для сборки и запуска приложения необходимы следующие библиотеки:

- OpenGL (3.3+)
- GLFW3
- GLEW
- CMake (3.10+)

## Сборка проекта

### Linux/macOS:

```bash
mkdir build
cd build
cmake ..
make
```

### Windows:

```cmd
mkdir build
cd build
cmake .. -G "Visual Studio 16 2019"
msbuild AircraftTailViewSimulator.sln
```

## Запуск

После успешной сборки запустите исполняемый файл:

```bash
./build/bin/AircraftTailViewSimulator
```

## Управление

### Джойстик Logitech Extreme 3D Pro:
- **Стick (влево/вправо)**: Управление креном (Roll)
- **Stick (вперед/назад)**: Управление тангажем (Pitch)  
- **Поворот стика**: Управление рысканием (Yaw)
- **Слайдер на левой стороне**: Управление тягой (Throttle)

### Альтернативное управление с клавиатуры:
- **Клавиши со стрелками вверх/вниз**: Тангаж (Pitch)
- **Клавиши со стрелками влево/вправо**: Крен (Roll)
- **A/D**: Рыскание (Yaw)
- **W/S**: Тяга (Throttle)

## Функциональные возможности

- Визуализация воздушного судна с фиксированной точки обзора от хвоста
- Отслеживание угловых перемещений в горизонтальной и вертикальной плоскостях
- Интеграция с джойстиком Logitech Extreme 3D Pro
- Отображение основных параметров полета (скорость, высота, углы)
- Режимы обучения с разными уровнями сложности

## Целевое использование

Программа используется на начальном этапе обучения пилотов гражданской авиации для формирования базовых навыков пространственной ориентации перед переходом к работе с приборной информацией.
