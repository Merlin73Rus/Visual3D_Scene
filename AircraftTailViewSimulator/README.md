# Программа для формирования навыков пространственной ориентации на основе визуализации воздушного судна с видом от хвостового оперения

## Назначение программы
Программа предназначена для формирования у студентов гражданской авиации базовых навыков пространственной ориентации посредством визуального анализа динамики полета. Реализована трехмерная модель воздушного судна, отображаемая с фиксированной внешней точки - с видом от хвостового оперения на неподвижный фон земли. Такая визуализация обеспечивает устойчивое восприятие пространственного положения и угловых перемещений воздушного судна в горизонтальной и вертикальной плоскостях. Программа служит основой для последующего перехода к интерпретации приборной информации и используется на начальном этапе обучения на процедурных тренажерах.

## Технические характеристики
- Использует графический движок OGRE3D для 3D-визуализации
- Поддержка управления с джойстика Logitech Extreme 3D Pro
- Реалистичная модель полета с учетом основных аэродинамических параметров
- Визуализация с фиксированной точки обзора сзади и сверху от самолета

## Управление
- Джойстик Logitech Extreme 3D Pro:
  - Ручка управления: отвечает за тангаж и крен
  - Руль (ноги): управление рысканьем
  - Сlider: регулировка тяги
  - Кнопка 1: выход из приложения

## Сборка и запуск
Для сборки проекта выполните:
```bash
mkdir build
cd build
cmake ..
make
./AircraftTailViewSimulator
```

## Структура проекта
- `include/` - заголовочные файлы
- `src/` - исходный код
- `assets/` - 3D-модели и текстуры
- `docs/` - документация
