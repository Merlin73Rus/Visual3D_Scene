# Программа для формирования навыков пространственной ориентации у студентов гражданской авиации

## Общее описание
Программа предназначена для формирования у студентов гражданской авиации навыков пространственной ориентации в условиях ограничения внешней визуальной информации. Обучение реализуется посредством поэтапной методики, основанной на манипуляции визуальными образами и развитии способности к ментальному вращению в перцептиво-моторном пространстве.

## Архитектура программы
Программа состоит из двух основных модулей:

1. **3DScene** - ядро на основе OGRE3D, отвечающее за визуализацию полета, физику полета и инструменты управления
2. **UI** - пользовательский интерфейс на основе Windows Forms, обеспечивающий управление тренировочным процессом

## Пять этапов обучения

1. **Адаптация к 3D модели воздушного судна** - вид от хвостового оперения на неподвижном фоне
2. **Основы маневрирования** - простые повороты, набор и снижение высоты
3. **Визуальный полет** - управление по внешним ориентирам
4. **Переход к приборному полету** - интеграция визуальной информации с показаниями приборов
5. **Приборный полет** - управление исключительно по авиагоризонту, высотомеру и указателю скорости

## Технические характеристики

- **Графический движок**: OGRE3D
- **Язык программирования**: C++
- **Пользовательский интерфейс**: Windows Forms (C++/CLI)
- **Ввод управления**: Клавиатура и мышь
- **Поддержка сценариев**: 5 обучающих этапов с различными уровнями сложности
- **Погодные условия**: Возможность симуляции различных метеоусловий
- **Время суток**: Настройка времени суток для тренировки в различных условиях освещения

## Функциональные возможности

- Система управления полетом с 4 степенями свободы (тангаж, крен, рыскание, тяга)
- Система инструментов для приборного полета
- Адаптивная сложность в зависимости от этапа обучения
- Система обратной связи и оценки навыков
- Поддержка различных сценариев полета (взлет, посадка, крейсерский полет)

## Целевое использование
Программа предназначена для использования в составе процедурных тренажеров на этапе начальной профессиональной подготовки пилотов гражданской авиации.

## Требования к системе
- Windows 7 или выше
- DirectX 9.0c или выше
- Видеокарта с поддержкой Shader Model 3.0
- 2 ГБ ОЗУ (рекомендуется 4 ГБ)
- 500 МБ свободного места на диске
