# Программа для формирования навыков пространственной ориентации у студентов гражданской авиации
## Техническая документация для регистрации в Роспатенте

### Общие сведения
**Название программы:** Программа для формирования навыков пространственной ориентации у студентов гражданской авиации

**Реферат:**
Программа предназначена для формирования у студентов гражданской авиации навыков пространственной ориентации в условиях ограничения внешней визуальной информации. Обучение реализуется посредством поэтапной методики, основанной на манипуляции визуальными образами и развитии способности к ментальному вращению в перцептиво-моторном пространстве. Программа включает пять последовательных этапов: от адаптации к трехмерной модели воздушного судна с видом от хвостового оперения на неподвижном фоне до пилотирования исключительно по приборной информации (авиагоризонт, высотомер, указатель скорости). На начальных этапах основное внимание уделяется визуальному восприятию динамики полёта, на последующих - интеграции зрительного образа с показаниями авиационных приборов, а на завершающем - переходу к управлению воздушным судном только по приборам. Программа предназначена для использования в составе процедурных тренажёров на этапе начальной профессиональной подготовки пилотов.

### Архитектура программного обеспечения

Программный комплекс состоит из двух основных компонентов:

1. **3D Scene Core** - модуль визуализации на основе движка OGRE3D
2. **User Interface** - модуль пользовательского интерфейса на основе Windows Forms

### Основные классы и компоненты

#### 1. CAviationSpatialTraining (3DScene/AviationSpatialTraining.h)
Основной класс управления авиационной программой тренировки. Обеспечивает:
- Управление 3D сценой
- Настройку этапов обучения
- Получение параметров полета
- Управление симуляцией

#### 2. OgreFlightRender (3DScene/OgreFlightRender.h)
Класс рендеринга на основе OGRE3D, реализующий:
- Физику полета
- Управление камерой
- Систему инструментов
- Погодные условия
- Время суток

#### 3. MainForm (UI/MainForm.h)
Основная форма пользовательского интерфейса, обеспечивающая:
- Управление этапами обучения
- Отображение параметров полета
- Настройку условий симуляции
- Визуализацию текущего состояния

### Пять этапов обучения

Программа реализует пятиступенчатую методику обучения:

1. **Адаптация к 3D модели** - вид от хвостового оперения на неподвижном фоне
2. **Основы маневрирования** - простые повороты, набор и снижение высоты
3. **Визуальный полет** - управление по внешним ориентирам
4. **Переход к приборному полету** - интеграция визуальной информации с показаниями приборов
5. **Приборный полет** - управление исключительно по авиагоризонту, высотомеру и указателю скорости

### Технические характеристики

- **Графический движок:** OGRE3D
- **Язык программирования:** C++
- **Пользовательский интерфейс:** Windows Forms (C++/CLI)
- **Система управления:** Клавиатура и мышь
- **Архитектура:** Модульная, с разделением на 3D-движок и UI
- **Поддержка сценариев:** 5 обучающих этапов
- **Погодные условия:** 3 уровня (ясно, облачно, туман)
- **Время суток:** Регулируемое от 0 до 23 часов
