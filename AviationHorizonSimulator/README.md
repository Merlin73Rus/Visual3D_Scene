# Программа для формирования навыков пилотирования по приборам с использованием авиагоризонта типа «вид с воздушного судна»

## Назначение программы
Программа предназначена для формирования у студентов гражданской авиации навыков пилотирования по приборам в условиях отсутствия внешней визуальной опоры. Обучение основано на использовании авиагоризонта типа «вид с воздушного судна» в сочетании с показаниями высотомера и указателя скорости. Программа реализует когнитивный подход к обучению и применяется на процедурных тренажерах на этапе начальной профессиональной подготовки.

## Технические характеристики
- Использует графический движок OGRE3D для 3D-визуализации
- Поддержка управления с джойстика Logitech Extreme 3D Pro
- Реалистичная модель авиагоризонта с отображением высотомера и указателя скорости
- Интерактивная система управления параметрами полета

## Управление
- Джойстик Logitech Extreme 3D Pro:
  - Ручка управления: отвечает за тангаж и крен
  - Руль (ноги): управление рысканьем
  - Сlider: регулировка тяги
  - Кнопка 1: выход из приложения

## Сборка и запуск
Для сборки проекта выполните:
```bash
mkdir build
cd build
cmake ..
make
./AviationHorizonSimulator
```

## Структура проекта
- `include/` - заголовочные файлы
- `src/` - исходный код
- `assets/` - 3D-модели и текстуры
- `docs/` - документация
