# Программа для формирования навыков пилотирования по приборам с использованием авиагоризонта типа «вид с воздушного судна»

## Описание

Программа предназначена для формирования у студентов гражданской авиации навыков пилотирования по приборам в условиях отсутствия внешней визуальной опоры. Обучение основано на использовании авиагоризонта типа «вид с воздушного судна» в сочетании с показаниями высотомера и указателя скорости. Программа реализует когнитивный подход к обучению и применяется на процедурных тренажерах на этапе начальной профессиональной подготовки.

## Особенности

- Визуализация искусственного горизонта с индикацией тангажа и крена
- Показания высотомера и указателя скорости
- Поддержка джойстика Logitech Extreme 3D Pro
- Физическая модель движения для корректного отображения параметров полета
- Когнитивный подход к обучению пилотированию по приборам

## Требования

- C++17
- CMake 3.10 или выше
- OpenGL 3.3 или выше
- Библиотеки: GLFW, GLEW, OpenGL

## Управление

### Джойстик Logitech Extreme 3D Pro:
- Ручка управления: крен и тангаж
- Руль направления: рыскание
- Рычаг газа: тяга двигателя

### Альтернативное управление с клавиатуры:
- Стрелки влево/вправо: крен
- Стрелки вверх/вниз: тангаж
- Q/E: руль направления
- W/S: газ
- ESC: выход из программы

## Сборка и запуск

1. Установите зависимости:
   - Ubuntu/Debian: `sudo apt-get install build-essential cmake libglfw3-dev libglew-dev`
   - Windows: установите CMake, GLFW и GLEW
   - macOS: `brew install cmake glfw glew`

2. Сборка проекта:
   ```bash
   mkdir build
   cd build
   cmake ..
   make
   ```

3. Запуск:
   ```bash
   ./AviationHorizonSimulator
   ```

## Архитектура

- `Aircraft`: модель воздушного судна с физикой полета
- `ArtificialHorizon`: визуализация искусственного горизонта
- `InstrumentsPanel`: высотомер, указатель скорости и курсоуказатель
- `JoystickHandler`: обработка ввода с джойстика
- `Application`: основной цикл приложения и управление ресурсами

## Назначение программы

Программа используется на начальных этапах подготовки пилотов для формирования навыков пилотирования по приборам. Обучение строится на когнитивном подходе, при котором студент учится ассоциировать показания приборов с ощущениями от маневрирования.
