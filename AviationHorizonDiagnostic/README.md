# Программа диагностики способности к пространственному анализу показаний авиагоризонта типа «вид с воздушного судна»

## Описание

Программа предназначена для объективной оценки уровня сформированности у студентов гражданской авиации способности к пространственному анализу показаний авиагоризонта типа «вид с воздушного судна». 

Программа реализует два последовательных диагностических модуля:

**Первый модуль**: включает серию из 50 изображений авиагоризонта с кренами различной величины и направления, демонстрируемых с интервалом три секунды; задача испытуемого - определить направление крена (левый или правый).

**Второй, усложненный модуль**: те же изображения дополнительно поворачиваются на углы, кратные 90°, что требует от испытуемого способности корректировать искаженное положение образа авиагоризонта и определять фактическое направление крена воздушного судна.

Результаты обоих модулей фиксируются в стандартизированном бланке и подлежат последующему статистическому анализу. Программа применяется для сравнительной оценки эффективности обучающих методик, в частности - при сопоставлении контрольной и экспериментальной групп обучающихся, и служит инструментом количественного измерения когнитивных навыков, лежащих в основе приборной ориентации в полете.

## Требования

- C++14 или выше
- SDL2
- SDL2_image
- CMake 3.10 или выше
- Джостик Logitech Extreme 3D Pro (или совместимый)

## Установка и сборка

1. Установите зависимости:
   ```bash
   # Ubuntu/Debian
   sudo apt-get install libsdl2-dev libsdl2-image-dev cmake
   
   # CentOS/RHEL/Fedora
   sudo dnf install SDL2-devel SDL2_image-devel cmake
   ```

2. Клонируйте репозиторий и перейдите в директорию проекта

3. Создайте директорию для сборки:
   ```bash
   mkdir build && cd build
   ```

4. Соберите проект:
   ```bash
   cmake ..
   make
   ```

5. Запустите программу:
   ```bash
   ./AviationHorizonDiagnostic
   ```

## Управление

- **Джостик Logitech Extreme 3D Pro:**
  - Кнопка 0 (спусковой крючок): выбор "левый крен"
  - Кнопка 1: выбор "правый крен"

- **Клавиатура:**
  - Клавиша ←: выбор "левый крен"
  - Клавиша →: выбор "правый крен"
  - Клавиша ESC: выход из программы

## Архитектура

- **HorizonDiagnosticApp**: Основной класс приложения, управляющий всем процессом диагностики
- **SlideData**: Структура для хранения информации о каждом слайде (путь к изображению, угол поворота, истинное направление крена)
- **generateTestSlides()**: Генерирует случайные слайды для обоих модулей
- **saveResults()**: Сохраняет результаты диагностики в файл

## Результаты

По завершении обоих модулей программа создает файл с результатами в формате:
- Количество правильных ответов в каждом модуле
- Общий процент правильных ответов
- Детализированные результаты по каждому слайду
- Время и дата проведения диагностики

## Особенности реализации

- Автоматическая смена слайдов каждые 3 секунды
- Поддержка вращения изображений в втором модуле на 90°, 180°, 270°
- Регистрация времени реакции пользователя
- Поддержка как джойстика, так и клавиатурного управления
- Сохранение результатов в текстовый файл для дальнейшего анализа
