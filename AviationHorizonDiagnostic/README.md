# Программа диагностики способности к пространственному анализу показаний авиагоризонта типа «вид с воздушного судна»

## Назначение программы
Программа предназначена для объективной оценки уровня сформированности у студентов гражданской авиации способности к пространственному анализу показаний авиагоризонта типа «вид с воздушного судна». Программа реализует два последовательных диагностических модуля. Первый модуль включает серию из 50 изображений авиагоризонта с кренами различной величины и направления, демонстрируемых с интервалом три секунды; задача испытуемого - определить направление крена (левый или правый). Во втором, усложненном модуле те же изображения дополнительно поворачиваются на углы, кратные 90°, что требует от испытуемого способности корректировать искаженное положение образа авиагоризонта и определять фактическое направление крена воздушного судна. Результаты обоих модулей фиксируются в стандартизированном бланке и подлежат последующему статистическому анализу. Программа применяется для сравнительной оценки эффективности обучающих методик, в частности - при сопоставлении контрольной и экспериментальной групп обучающихся, и служит инструментом количественного измерения когнитивных навыков, лежащих в основе приборной ориентации в полете.

## Технические характеристики
- Использует графический движок OGRE3D для 3D-визуализации
- Поддержка управления с джойстика Logitech Extreme 3D Pro
- Два диагностических модуля по 50 изображений каждый
- Автоматическое сохранение результатов в файл
- Интервал отображения изображений 3 секунды

## Управление
- Джойстик Logitech Extreme 3D Pro:
  - Кнопка 0: ответ "левый крен"
  - Кнопка 1: ответ "правый крен"
  - Кнопка 2: выход из приложения

## Сборка и запуск
Для сборки проекта выполните:
```bash
mkdir build
cd build
cmake ..
make
./AviationHorizonDiagnostic
```

## Структура проекта
- `include/` - заголовочные файлы
- `src/` - исходный код
- `assets/` - 3D-модели и текстуры
- `docs/` - документация
